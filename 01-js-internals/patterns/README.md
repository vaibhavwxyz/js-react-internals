# Must-Do Pattern Problems

Practice set from [takeuforward — Must Do Pattern Problems Before Starting DSA](https://takeuforward.org/strivers-a2z-dsa-course/must-do-pattern-problems-before-starting-dsa).

Each file has a one-line problem statement and the **exact expected output** — no hints, no solution.
Fill in the function body and run it:

```bash
node 01-js-internals/patterns/pattern-01-rectangular-star.js
```

Compare your output with the `Expected output` block at the top of the file (whitespace matters — the expected block starts at column 0).
